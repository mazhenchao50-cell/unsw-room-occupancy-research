# UNSW教室占用率历史研究：当前运行说明

正式方案为unified_v6（2026-11-23）。已见教室的占用率由两段式模型给出（补充研究14）：原分类器给出“未实际上课/低利用率”概率p，另一LightGBM只用正常上课课次预测开课时占用率m1；均值p×低利用率平均值+(1−p)×m1用于第①项，显示占用率在提示时取低利用率平均值、否则取m1，因此“显示占用率<10%”与正式提示一致；单一LightGBM保留为regression_prediction供对照。低利用率提示保留原固定双分类器与公共假日日历提示，并加入日历情境历史三模型多数决补充；两种分数分别展示，不当作校准概率。未见教室由cold_week模型处理（补充研究11：v8静态特征加教学周次，内层留一教室选型）。界面默认使用该方案；原始基线只供明确选择的对照。

低利用率正例几乎全部是原作者考勤表中没有的课次（课表有但未实际上课，即计划书的No-show，见补充研究13）；第③项按宏RMSE≤0.18分支通过，相对随机差距分支对口径敏感、不作为依据（补充研究12）。2026-11-24复核（补充研究15–19）：四周合并显著优于惯性基线；①在未使用的2018学期复现；①②不依赖报名人数，③在报名偏差±10%内成立；正式模型SHAP方向符合预期；无课时段至少20%被自发占用，空教室推荐采用历史时段规则；同等信息下原论文口径误差差于原论文，优势来自学期内累积的课程历史。第③项按计划书常规留一教室口径达标（0.172），按严格时间顺序的预测口径为0.185，未达标（补充研究20）。2026-11-24更正：第①项两条基线改为与模型同等信息（均使用测试周之前的全部周），第12周相对历史均值改善42.61%（原口径44.33%），仍通过。两段式第一段概率未经校准这一点已用补充研究23检验：Platt校准没有改善Brier与RMSE，未采用。第④项的真人试用已准备并冻结协议（`usability/研究协议.json`，任务版本trial_v7_20261124：5–8名非项目成员完成课程复核与空教室候选4个任务并填写SUS；通过标准为整体独立正确完成率≥80%、每个任务≥60%、SUS平均≥68），目前0人，试用后用`03、系统应用/代码/usability.py`汇总。详见evaluation_protocol.md。

原始UNSW输入在`01、数据处理/原始数据/UNSW/`，共14份完整CSV。它们与UNSW官方data.zip逐文件SHA256一致；清洗输入清单位于`01、数据处理/清洗产物/input_manifest.json`。不可用相似文件替换。来源见sources.md和data_card.md。原始数据、模型和日志不进入公开源码包。

报名人数已有原作者定义及预测使用依据，继续用于本项目历史研究。尚未核实的是公开CSV逐值取得时间和双表差异原因；不把它写成字段无来源或已证实泄漏，也不将当前结果称为实际课前部署验证。对应官方链接、页码和原文哈希随源码包保存在`05、文档依赖/依赖/unsw_field_evidence.json`。

当前验收入口是`02、模型实验/生成产物/acceptance/README.md`，数值证据为同目录numeric_status.json；全部815条跨周预测位于`02、模型实验/生成产物/unified/time_predictions.csv`。重建状态以最新release_validation目录的verification.json为准；它按源码ZIP哈希绑定，旧版本通过不能覆盖新修改。

## 使用

主流程为历史课程复核：可选第8、10、11、12周日期，中、英、韩、日可切换。默认展示当天完整课次，按模型提示排列；选择课次查看两个分类器得分、全部特征贡献（unified模式的占用率解释针对两段式中的开课条件回归m1，并校验贡献之和）及此前三次课程信号，填写备注并导出完整依据。每个分类器的贡献先重构对数几率，再转换为分数；两个分数平均后与实际提示核对，不能将对数几率贡献误读为概率百分点。切换课次会清空旧备注。2026-11-24起（启发式评审F1–F5）：清单首列为“⚠ 需复核（原因）”，模型分数移入研究用折叠区；提示原因先给普通话结论与可读依据；开始时间为15分钟一档下拉框；时段跨午夜只在候选区报错。低利用率是整节课观测峰值/座位数小于10%，不等于某15分钟无人。空教室候选（2026-11-24起）采用补充研究19的历史时段规则（`03、系统应用/代码/free_slot_rule.py`）：所选时段内无已知课程（含开课前15分钟），且该教室同星期同时段在更早几周被自发占用（≥5人）的比例低于50%；仅覆盖工作日8:00–20:00。历史回放中此规则推荐的时段84.1%实际空闲（计入下课后留下的人时56.8%）。候选不代表现场已确认可用，开放权限与预约须另行核对。

正式模型缺失或来源改变时停止展示正式预测，旧基线必须主动选择。四周使用各自只见过此前数据的模型，不拿第12周模型回算较早周。研究详情提供误报、漏报及回归解释；分类器得分不是经过校准的实际发生概率。人工复核记录不能取消课程或授予进入权限。

原定前三项的阈值和评估样本见evaluation_protocol.md。范围限定为UNSW历史数据，第四项后续处理。实验失败、弃用方案、修复原因及导师答辩依据统一保留在项目外层的两本正式Word白皮书中。文件结构和依赖图见项目实施目录说明.md及交接资料。
