# 项目实施目录说明

以后项目的运行代码、原始数据、清洗结果、模型、测试和运行日志都在本目录维护。根目录按工作环节分为五组；各组内部再分代码、原件或产物。项目内`.venv-repro/`为旧环境，当前电脑已无法可靠启动；本轮验证改用`D:\ProjectTools\UNSW_RoomReplay_Python313\.venv`，其依赖和缓存位于D盘，但依赖电脑原有的Python 3.13.17基础运行时。课程提交件和两本Word白皮书仍在各自的交付目录。

| 文件夹 | 包含内容 | 使用规则 |
| --- | --- | --- |
| `01、数据处理/` | `代码/` 清洗程序；`原始数据/UNSW/` 的 14 个原始 CSV；`原始数据/UCI/` 的公开扩展数据；`清洗产物/` | 原始数据不手工改，清洗产物由程序生成。原来 5 号目录的数据原件都在这里 |
| `02、模型实验/` | `代码/models/` 的主模型和候选实验；`生成产物/` 的模型、预测、指标和图表 | `revised/` 是当前应用使用的主结果；其他实验单独标注范围 |
| `03、系统应用/` | `代码/` 中的 Streamlit 界面、四语文案、候选回放、时段建议、核查单和试用汇总 | 启动文件为 `代码/app.py` |
| `04、运行验证/` | `代码/` 中的一键重建、隔离复现、验证和审计；`测试/`；`日志/` | 重建从第一处失败的日志定位原因，不编辑日志中的源码副本 |
| `05、文档依赖/` | `文档/` 的数据卡、协议、复现说明和历史状态；`依赖/` 的安装清单 | 文档记录范围，依赖文件供本机环境安装 |

## 常用命令

在项目实施目录（本地为 `8、项目实施（预测与推荐）`，源码包中为解压后的根目录）运行。已有清洗产物时，从第二条启动命令开始即可。

```powershell
.venv-repro\Scripts\python.exe "04、运行验证\代码\run_all.py" --profile core
.venv-repro\Scripts\python.exe -m streamlit run "03、系统应用\代码\app.py"
.venv-repro\Scripts\python.exe "04、运行验证\代码\verify_reproduction.py" --profile core
```

默认原始输入路径为 `01、数据处理/原始数据/UNSW/`。14 个 CSV 在搬迁前后均与 `01、数据处理/清洗产物/input_manifest.json` 中的 SHA256 一致。运行事实以代码、原始数据和本次生成的报告共同核对；项目叙述性进度继续写入两本 Word 白皮书。
