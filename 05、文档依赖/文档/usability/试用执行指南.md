# 真人试用执行指南（主持人用）

任务版本：**trial_v7_20261124**（记录中 app_version 填此值）。研究协议与通过标准见 [研究协议.json](研究协议.json)，**第一位参与者开始前冻结，之后不得修改**。旧版任务（unified_v6_20261123、audit100_20261118）适用于没有空教室候选的旧界面，已停用。

## 一、准备（约10分钟）

1. 参与者：5–8人，未参与本项目开发与汇报准备（本组成员不能当参与者）。只用匿名编号 P01、P02…，不记姓名、学号、联系方式。
2. 打印给参与者的材料：[任务卡（中韩双语）](任务卡（中韩双语）.md)、[SUS问卷（中韩双语）](SUS问卷（中韩双语）.md)、[知情同意（中韩双语）](知情同意（中韩双语）.md)。本指南和评分标准**不要**给参与者看。
3. 记录：用 Excel 打开 [记录表.csv](记录表.csv)，每位参与者填一行。准备秒表（手机即可）。
4. 启动系统（项目复现环境，在 `8、项目实施（预测与推荐）` 目录下运行）：

```powershell
& '..\11、运行环境与验证存档（原D盘）\1、运行环境\项目复现环境_RoomReplay\.venv\Scripts\python.exe' -m streamlit run '03、系统应用\代码\app.py' --client.toolbarMode minimal
```

5. 每位参与者开始前**刷新浏览器页面**，让界面回到初始状态（语言、日期、时间、座位都恢复默认）。

## 二、开场（逐字读，约1分钟）

> 这是一个用UNSW大学2017年历史数据做的教室使用系统演示。我会请你完成4个小任务，请一边操作一边说出你在想什么。没有对错，我们测试的是系统，不是你。遇到困难可以说出来，我可能不会马上帮你。你可以随时停止。

参与者口头同意后开始（见知情同意）。

## 三、四个任务

每个任务：读任务卡 → **开始计时** → 参与者说“完成”或放弃 → **停止计时** → 问理解题 → 按下面标准编码。

**提示规则**：参与者明确求助，或卡住超过2分钟时，才可以给一句提示，并把该任务 assisted 记为 yes。不要提前解释界面，也不要在问理解题前透露答案。

| 任务 | 操作（任务卡原文的要点） | 理解题 | 正确编码 | 判为正确的标准 |
|---|---|---|---|---|
| T1 | 日期选2017-10-16，在“历史课程复核清单”中找一节标有“⚠ 需复核”的课，选中并展开“为什么提示这节课” | 这条提示能否说明这间教室现在没人、可以直接去用？ | `low_use_not_vacancy` | 说出“不能”，且理由涉及：提示是预测整节课人数很少/可能没上课，不等于现在没人或可以进入 |
| T2 | 对同一节课选一个复核结果、写一句备注、导出复核记录 | 这份记录能否直接用来取消这门课或把教室让给别人？ | `review_not_decision` | 说出“不能”，理由涉及：只是需要人工核实的线索 |
| T3 | 2017-10-18，18:00开始，90分钟，30个座位；选一间候选，看列出原因，保存核查单 | 这间教室是否已确认可以用？系统根据什么列出它？ | `candidate_needs_verification` | 说出“未确认/要现场核实”，并提到课表此时无课或过去同时段很少有人使用（任一即可） |
| T4 | 2017-10-16，13:00开始，60分钟，100个座位；没有候选时按系统建议继续查 | 系统建议改到几点？原时段没有候选是否说明所有教室都有人？ | `adjust_to_later` | 说出16:00，且回答“不说明所有教室都有人” |

- outcome：`completed`（完成操作）/ `failed`（做错且自认为完成）/ `abandoned`（放弃）。
- answer：正确编码 / `incorrect`（答错或只答对一半）/ `no_answer`（不回答）。只答对一半一律记 `incorrect`。
- 参与者原话、犹豫的地方、点错的位置写进 notes，这是改进界面的主要依据。

## 四、SUS问卷（约2分钟）

四个任务结束后，请参与者独立填写SUS问卷（1=非常不同意，5=非常同意），主持人不解释题意。把10个分数原样填入记录表 SUS1–SUS10，**不要自己换算**，程序会按Brooke（1996）规则计算0–100分。

## 五、填写记录表

每人一行；`confirmed_human_trial` 只在真人实际完成试用后填 `yes`。日期写实际试用日期（YYYY-MM-DD），language 写参与者使用的界面语言（zh/en/ko/ja）。

## 六、汇总

全部参与者结束后，在 `8、项目实施（预测与推荐）` 目录下运行：

```powershell
& '..\11、运行环境与验证存档（原D盘）\1、运行环境\锁定验证环境_Audit100\.venv\Scripts\python.exe' '03、系统应用\代码\usability.py' --records-csv '05、文档依赖\文档\usability\记录表.csv' --output '02、模型实验\生成产物\usability\summary.json'
```

程序会拒绝空模板、重复编号、异常耗时、非法分数和混用版本，并按冻结的通过标准判定：参与者≥5人，整体独立正确完成率≥80%，每个任务≥60%，SUS平均≥68。少于5人只报告观察结果，不判定通过与否。
